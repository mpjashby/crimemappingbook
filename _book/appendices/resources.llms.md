# `<a id="sec-resources"></a>`{=html}Appendix F --- Example reports and templates

These files provide examples to learn from and starting points for your own crime-mapping projects. You can view a finished report in your browser, or download its Quarto or R source file to see how the text and R code produce the report.

  Resource description                                                                                                                                                                                                                                       Source                                                                 Output
  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- ---------------------------------------------------------------------- ------------------------------------------------------------------------
  **Medellín homicides: map.** An example of how to create a short report in Quarto, including explanatory text, a density map, a figure caption and a cross-reference. More details in [Chapter 11](../11_writing_reports/index.llms.md).                   [Download QMD](../resources/reports/medellin_homicides_map.qmd)        [Download HTML](../resources/reports/medellin_homicides_map.html)
  **Medellín homicides: table.** An example of how to create a short report in Quarto, including a table and associated explanatory text. More details in [Chapter 11](../11_writing_reports/index.llms.md) and [Chapter 14](../14_no_maps/index.llms.md).   [Download QMD](../resources/reports/medellin_homicides_table.qmd)      [Download HTML](../resources/reports/medellin_homicides_table.html)
  **Fire hotspots in Edmonton.** An example of how to create a longer report in Quarto about demand for fire and rescue services.                                                                                                                            [Download QMD](../resources/reports/edmonton_fire_rescue_demand.qmd)   [Download HTML](../resources/reports/edmonton_fire_rescue_demand.html)
  **Illegal waste dumping in Yarra.** An example of how to create a longer report in Quarto comparing waste dumping between suburbs.                                                                                                                         [Download QMD](../resources/reports/yarra_waste_dumping.qmd)           [Download PDF](../resources/reports/yarra_waste_dumping.pdf)
  **Crime mapping script template.** A template for organising an R script. Replace the guidance comments with the code and explanation for your analysis. To use a source file or template, save it in the relevant folder of your crime mapping workspace and open it in Positron. Keep original downloaded data in `data/raw/`, as explained in [Section 1.5](../01_getting_started/index.llms.md#sec-create-project).
